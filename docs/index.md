# NetRollout documentation

NetRollout pushes configuration snippets to many network devices at once over SSH, verifies each device's configuration afterwards, and records every result. These guides cover installing it, running it, and using it.

| Guide | For | What it covers |
| --- | --- | --- |
| [Installation](install.md) | Admins | Requirements, Windows Setup, Linux install, first sign-in, certificates, uninstall, troubleshooting |
| [Admin guide](admin-guide.md) | Admins | NetRollout Manager, the `netrollout` commands, updates, backups, users and sign-in, System Settings, monitoring |
| [User guide](user-guide.md) | Operators | Inventory, security profiles, variable mappings, rollouts, results, analytics |
| [CLI](cli.md) | Engineers | `netrollout-cli` flags, input files, exit codes, logs |
| [Security](security.md) | Reviewers | How NetRollout protects credentials, sessions and data |
| [Architecture](architecture.md) | Developers | Tech stack, containers, flows, packages, object and data model |
| [Roadmap](roadmap.md) | Everyone | What comes after 1.0 |

Also on GitHub: [contributing](../CONTRIBUTING.md), the [security policy](../SECURITY.md) for reporting a vulnerability, and the [changelog](../CHANGELOG.md).

New here? Start with [Installation](install.md), then the [User guide](user-guide.md).
