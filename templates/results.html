                        no / undo / delete / unset), or already there
                        unchanged, or shown with the device's defaults. A command the configuration doesn't show is
                        rejected when the device replied to it, else
                        review - a value the device rewrote: decide it with the
                        evidence below. That the device replied counts, never what it said.
