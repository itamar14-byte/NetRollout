# Frontend (templates/)

Loaded only when working under `templates/`. Claude writes the templates/HTML directly (see the root CLAUDE.md, Working style).

## Frontend

Always-dark enterprise aesthetic — permanently dark, no toggle. Key design elements:
- **Fonts:** Inter (body) + JetBrains Mono (monospace/badges)
- **Accent color:** `#00bcd4` cyan
- **Custom classes:** `.nr-card`, `.nr-card-accent`, `.nr-card-body`, `.nr-badge`, `.nr-label`, `.nr-back-btn`
- **Dot-grid background:** `body::before` at `z-index: -1` (NOT 0 — traps modals)
- **`.container` must NOT have z-index** — breaks Bootstrap modal stacking
- All Bootstrap components overridden in the three skeletons (`base.html`, `operator_base.html`, `admin.html`) to match the dark theme. What all three write the same is `_theme_core_css.html` (tokens, focus, typography, dropdowns, cards, forms, buttons, tables, alerts, modals, badges, scrollbars), included first in each `<style>`; what only `base.html` and `operator_base.html` share (`admin.html` writes its own: cards, primary/success buttons, disabled/invalid fields, the password error line) is `_theme_pages_css.html`, right after it. A skeleton's own rules follow and override them. Moving a rule between these files can change the cascade: prove it with every page's computed styles at rest and with :hover/:focus/:active forced, disabled and invalid (that's how `.btn-outline-secondary:hover` was found to stay in base/operator_base: it must follow base's `.input-group .btn-outline-secondary`).
- All operator pages extend `operator_base.html`. Topbar and footer are automatic.
- **Admin pages extend `admin.html`** — standalone template (does not extend `base.html` or `operator_base.html`). Own topbar with ← Home button, own collapsible sidebar (Access / Observability / System sections), own footer, restart button. Sub-pages: `admin_users.html`, `live_sessions.html`, `admin_audit.html`, `admin_analytics.html`, `admin_settings.html`, `server_management.html`.
- **nginx** sits in front of Waitress: the nginx image (`deploy/nginx/`, its site from `site.conf.template` — see the root CLAUDE.md), in dev too (the dev stack, `compose.dev.yaml`, forwards to the app on the host). Flask uses `ProxyFix(x_for=1, x_proto=1, x_host=1)`. SSE (`/rollout/stream/<job_id>`) streams unbuffered (its own location, plus the app's `X-Accel-Buffering: no`). `/grafana/` is Grafana, for signed-in admins only. Pages that refresh or poll by themselves must mark those requests as background (`X-NR-Background: 1` header, or `?_bg=1` on an automatic reload) — otherwise they keep an idle session alive (`_idle_timeout.html`).
- **Vendor logos**: `VENDOR_LOGOS` dict in `src/webapp/build.py` maps Netmiko device_type → a logo URL: Simple Icons' CDN, else homarr-labs dashboard-icons on jsDelivr (Aruba, Check Point), Arista's Wikimedia wordmark (black — `operator_base.html` renders it white: `img[src*="Arista-networks-logo"]`). Registered as Jinja2 global — available in all templates as `VENDOR_LOGOS`.
- **NrSelect widget**: custom FortiGate-style dropdown — search box, scrollable list, shield icon, cyan checkmark. What every picker does alike (the trigger, the search, outside clicks, closing with its modal) is `nrSelectShell(container, filter, modal)` in `_op_widgets_js.html`; each picker keeps its own render / pick / API: `initNrSelect` (returns `{getValue, setValue, reset}`) and `initPlatformSelect` in `inventory.html`, `initTestDevSelect` in `security.html`, `initAttrSelect` in `variable_mappings.html`.
- **Inventory cards**: thin horizontal rectangles — vendor badge (CDN SVG + BI router fallback) + label + IP. Hover tooltip (FortiGate-style fixed panel). Click → edit modal.
- **Assign board** (Security Profiles + Variable Mappings devices modals): shared `nrAssignBoard()` in `_op_widgets_js.html` (`operator_base.html` <head>). Two columns, Assigned | Available/Eligible; drag either way or click/Enter a card to move it. Moves are staged; Save shows `(+N / −M)`. Security saves via `/inventory/bulk_assign` (`profile_id: null` unassigns) and warns when devices lose their profile; mappings save via `/mappings/bulk_assign` with `device_ids` + `remove_ids`.

- **Shared includes** (both `admin.html` and `operator_base.html`): `_drain_banner.html` (shown while the server drains for a stop/restart; reloads when a new instance answers), `_maintenance_banner.html`, `_restart_modal.html` + `_restart_script.html` (the admin Restart: "when finished" / "now"; include the script inside `{% with restart_btn, restart_icon, restart_label %}` naming the sidebar button). In all three skeletons: `_theme_core_css.html`, `_user_menu.html` (`{% with admin_icon %}`: the admin link's icon, none on admin pages), `_footer.html`, `_idle_timeout.html`. `_flash.html` (`{% with flash_class, flash_width %}`) on `admin.html`, `operator_base.html` and the sign-in / register / 2FA / change-password pages; `_otp_boxes.html` (the 6-digit 2FA entry; `otp_autofocus`) on 2FA enroll + verify; `_password_rule_script.html` on register + change password; `_access_status.html` on System Settings + Server Management. Change them once, not per template.
- **Macros** (`{% from "_x.html" import x %}`): `delete_modal` (`_delete_modal.html`: the "IRREVERSIBLE ACTION" confirmation, Security + Variable Mappings), `property_modal` (`_property_modal.html`: the new-property form, Properties + the quick create on Inventory and Variable Mappings; field ids = prefix + Label / Name / Icon / IconPreview / IsList / Error; the footer is the `{% call %}` body), `querybuilder_style` (`_querybuilder_style.html`: Analytics' and Admin Analytics' QueryBuilder CSS in the page's accent).
- **Named styles instead of repeated inline ones** (`_classes_css.html`, included last in each skeleton's `<style>`, before the page's own): `nr-label-hint` (a hint inside a label), `nr-help` / `nr-help-spaced` / `nr-help-text` (help under a field), `nr-badge-danger` (with `nr-badge`), `nr-kpi-value`, `nr-section-title(-tight)`, `nr-page-title` / `nr-page-subtitle`, `nr-note(-tight)`, `nr-warning-note`, `nr-mono` / `nr-mono-caption`, `nr-accent-danger` / `nr-accent-soft-line` (with `nr-card-accent`), and the colours `nr-muted`, `nr-faint`, `nr-accent`, `nr-accent-icon`, `nr-danger`, `nr-danger-soft`, `nr-strong`. Use them rather than writing the same `style=` again; one-off layout (a modal's width, a margin) stays inline. An inline style beats normal rules and a class doesn't - elements whose style a script changes, or with `display`, keep theirs inline.
- **CSRF in scripts**: `CSRF_TOKEN`, defined once in `<head>` (`_op_widgets_js.html` for operator pages, `admin.html` for admin pages) — send it as `X-CSRFToken`; never declare another copy in a page (a second top-level `const CSRF_TOKEN` is a SyntaxError that stops the page's script). `base.html` pages have none (they only post forms, with the hidden `csrf_token` input).

## Frontend asset structure
Per-page CSS and JS live inline in `{% block extra_style %}` and `{% block extra_script %}` blocks — no build pipeline, one file per page. The operator pages' shared widgets (reachability helpers, the assign board, the NrSelect shell, autoSlug, the icon picker) are `_op_widgets_js.html`, included in `operator_base.html`'s `<head>` so page scripts can call them; their CSS `_op_widgets_css.html`. Extracting to `static/css/` and `static/js/` is deferred post-v1.0.
